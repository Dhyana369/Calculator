# Calculator

A basic calculator project built using HTML, CSS, JavaScript, and Java.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Clear and backspace
- Division by zero handling

## Versions

- Web Calculator — HTML, CSS, JavaScript
- Console Calculator — Java

## How to Run

### Web
Open `index.html` in a browser.

### Java
Run `Main.java`.

## Technologies

HTML | CSS | JavaScript | Java
